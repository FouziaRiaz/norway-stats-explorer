# Norway Stats Explorer

A React + TypeScript portfolio project using Statistics Norway's official StatBank PxWebApi v2.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL, normally `http://localhost:5173/`.

## What it demonstrates

- React + TypeScript + Vite
- Live API integration with Statistics Norway
- SSB table search
- JSON-stat2 metadata parsing
- Live StatBank data preview
- Loading and error states
- Responsive UI
- GitHub-ready `.gitignore`

SSB's PxWebApi v2 provides access to StatBank tables through GET/POST requests and does not require registration. SSB documents JSON-stat2 as the default data format and describes the table search, metadata, and data endpoints in its API guide.
